## Decisions taken by the Planner
- Real-database tests run against the Supabase CLI local stack (Docker, `supabase start`), not a paid staging project: no spend, reproducible in GitHub Actions (public repo, free minutes). The staging Supabase project and Vercel env are the human's (P0-6 money); docs/STAGING.md gives the exact steps and the CI secrets to set.
- Error tracking: Sentry SDKs behind env (SENTRY_DSN unset = disabled, EU region via the DSN host). Creating the Sentry org is the human's; code lands disabled. Cost meter: a usage_events table (model, tokens in/out, voice seconds, frame bytes, workspace, user, session) plus a SQL view with a price table in CHF; usage_counters caps stay.
- Frame minimisation without a new deletion path: the vision route classifies first and stores a frame only when its events are not all routine; routine frames are never written; the existing retention cron purges the rest; default retention 30 days (RETENTION_DAYS gains no option, 90 -> 30 default).
- Capture scope: getDisplayMedia prefers a window/tab (displaySurface "window", monitorTypeSurfaces "exclude"); the Electron handler offers windows and screens; whole-monitor remains an explicit choice in the picker, not the default.
- Auto-update: electron-updater with GitHub releases (repo K3NTAW/ai-apprentice-desktop), signing config from env (CSC_NAME, APPLE_API_KEY/ISSUER/KEY_ID), identity stays null when the env is absent so unsigned local builds keep working.
- Legal drafts are documents under docs/legal/, English, general, Swiss nFADP + GDPR, placeholders marked; marketing pages untouched (publishing is the human's and needs an entity).
